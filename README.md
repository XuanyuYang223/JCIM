# JCIM

Research on reusable local structural representations in small molecular models.

## Research question

Do small models trained on different molecular structures learn local representations that transfer across substitution positions and molecular contexts? Does this reuse help them handle unseen structural combinations?

## Initial scope

- Generate diverse substituted benzene molecules by varying substituent identity, relative position, and side-chain length.
- Split by complete molecular identity, keeping every SMILES variant of a molecule in the same partition.
- Hold out substituent-position and substituent-context combinations for evaluation.
- Start with substituent and functional-group identification and localization, relative-position classification, and atom-to-atom shortest-path prediction.
- Compare models with matched architectures, training-set sizes, and training budgets; include repeated seeds and randomly initialized controls.
- Measure unseen-combination accuracy, cross-position readouts, layerwise CKA and Procrustes alignment on shared evaluation molecules, and adaptation data requirements.

The working hypothesis is that representations retain shared substituent information while adapting to position and molecular context. High CKA alone is insufficient evidence of functional reuse, and training is not assumed to increase CKA.

## Local pilot

The first pilot uses 3,840 RDKit-generated molecular graphs with eight target-group families, ten reference-group families, four spacer lengths on each side, and three ring positions. Atom features contain element identities and ordinary atom descriptors plus explicit query-atom and target-fragment masks. This is query-conditioned structural analysis; automatic functional-group discovery or localization is not measured.

A small six-layer graph neural network jointly classifies the target family, ring position, and shortest path between two marked terminal-group roots. Path lengths vary from 3 to 11 bonds. Graph inputs avoid dependence on SMILES ordering; canonical, map-free molecular identities determine every split.

Experience A excludes the entire fluoro-meta cell. Experience B excludes the entire chloro-meta cell. Both use the same 2,279 shared training molecules and 92 molecules from their respective additional cell, for 2,371 training identities each. Three seeds share exact initial weights between A, B, and the corresponding random control. Training runs for a fixed 60 epochs; OOD labels never select checkpoints.

The fluoro family includes fluorinated side chains when its spacer length is positive. Direct aryl-F molecules are reported separately. Family labels can be decoded directly from raw atom features, so their cross-position readout is a control rather than evidence that training induced reuse. Relational probes and frozen-encoder distance adaptation provide additional functional measurements.

## Reproduce on Windows

The recorded environment uses Python 3.13 and PyTorch with CUDA 12.8. The installation command below reproduces its package versions; `--device cpu` can be used without a compatible GPU.

```powershell
uv venv --python 3.13 .venv
uv pip install --python .venv\Scripts\python.exe torch==2.11.0+cu128 --index https://download.pytorch.org/whl/cu128
uv pip install --python .venv\Scripts\python.exe -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -u -m jcim.run --config configs\pilot_v1.json --output experiments\pilot_v1
.\.venv\Scripts\python.exe -m jcim.verify experiments\pilot_v1
```

Existing result directories cannot be overwritten. Use a new output directory for each rerun. A short pipeline check can use `--epochs 2 --seeds 0 --output experiments\smoke_v1`.

## Records and interpretation

Each run archives configuration, package/device information, source hashes, canonical molecule metadata, graph arrays, identity splits, predictions, checkpoints, layerwise representations, numerical result tables, an English report, and a SHA-256 manifest. Checkpoints and full representation arrays are retained locally and excluded from Git. In molecule metadata, atom-map numbers in `atom_map_reference_smiles` equal the archived graph atom index plus one; query indices refer to these graph arrays, not to a new parse of the map-free canonical SMILES. Reports are generated by `jcim/report.py`; documentation corrections to a frozen run should be saved separately, preserving its original manifest.

Cross-position family probes fit on ortho molecules and evaluate on distinct meta molecules. Cross-family position probes fit on six families and evaluate on fluoro/chloro molecules, using both local and graph readouts. CKA and Procrustes compare the same ordered test molecules, including random-model and same-data/different-seed controls.

Few-shot adaptation fits a fresh, fixed-regularization distance readout on a frozen encoder using 8, 24, or 64 labeled fluoro-meta molecules, with five nested support-set repeats. The support molecules and fixed test molecules never overlap. A has never seen those support molecules or the fluoro-meta combination during pretraining; B has seen the support pool and is a seen-combination reference. This measures readout sample efficiency, not full-model fine-tuning.

The pilot can establish feasibility and expose confounds. It cannot establish that representation similarity causes transfer, or generalization to unrestricted chemical space.

## First completed result

The three-seed pilot is complete. All six trained models achieved 100% on all three original tasks in the shared test partition, including the held-out family-position cells. Raw input features and untrained encoders also reached 100% cross-position family readout, making that probe uninformative about what training added. Local cross-family position readout remained weak.

With 64 fluoro-meta labels, a new distance readout on Experience A's frozen representations reached 75.6% +/- 5.6% accuracy across encoder seeds, compared with 24.1% +/- 5.1% for untrained encoders and 26.9% for raw features. This is a representation-readability result: the trained models' existing heads already achieved 100% with zero additional labels on the same test task. It does not establish a practical reduction in required adaptation labels or a causal role for local representation reuse.

See the [frozen numerical report](experiments/pilot_v1/REPORT.md), [result figure](experiments/pilot_v1/figures/pilot_summary.png), and [independent interpretation](maintenance/BASELINE_AUDIT.md). The [independent data audit](maintenance/DATA_ARCHIVE_AUDIT.json) reconstructed all 3,840 molecules from archived mapped SMILES and found no graph, label, or identity-partition inconsistencies. The present tasks have reached a behavioral ceiling; harder compositional holdouts and less trivial local probes are needed to test the core hypothesis.

## Harder experiment

The [hard-v2 protocol](configs/HARD_V2_PROTOCOL.md) replaces elemental-family labels with eight equally composed connectivity motifs, adds aromatic nitrogen and a third distractor, and removes the oracle fragment mask. The 6,912-identity dataset reserves common motif-position combinations unseen by either training experience. Both experiences have 1,386 training identities with matched motif counts. Local readouts use a single marked attachment atom whose raw attributes are identical across motifs.

Actual few-shot adaptation retains the original task heads and fine-tunes all model parameters on support identities excluded from both pretraining experiences. Both IID guard sets are measured alongside the common OOD set. Raw-root and random-encoder probes, matched initialization, three seeds, and factorial geometry comparisons remain part of the protocol.

```powershell
.\.venv\Scripts\python.exe -u -m jcim.hard_run --config configs\hard_v2.json --output experiments\hard_v2
.\.venv\Scripts\python.exe -m jcim.hard_verify experiments\hard_v2
```

The shorter `experiments/smoke_hard_v2` run checks the pipeline with two epochs and two adaptation updates; it is not the primary result. All experiment records retain exact bytes in Git so newline conversion cannot invalidate their archived checksums.

### Completed harder result

Across three seeds, both experiences reached 100% accuracy on all original tasks in their own familiar-combination IID tests. Common unseen-combination motif accuracy was 0.0% for A and 4.2% +/- 7.1% for B, even though position accuracy remained 100%. The final local cross-position motif readout had balanced accuracy 21.0% for A and 20.8% for B, compared with 37.1% for random encoders and 12.5% for raw roots. The specified local probe therefore shows no trained advantage.

With 32 new labeled molecules, full-model adaptation raised common OOD motif accuracy to 91.1% for A and 95.3% for B, versus 79.1% from random initialization. Their own-IID motif accuracies fell from 100% to 70.3% and 52.7%. With 128 new labels, both reached 100% OOD motif accuracy while retaining only 62.3% and 37.9% own-IID motif accuracy. OOD adaptation improves performance but does not preserve the old motif-position mappings.

See the [frozen hard-v2 report](experiments/hard_v2/REPORT.md), [nine-panel result figure](experiments/hard_v2/figures/hard_summary.png), [motif structures](experiments/hard_v2/figures/motif_grid.png), [independent interpretation](maintenance/HARD_V2_INTERPRETATION.md), and [independent archive audit](maintenance/HARD_V2_DATA_AUDIT.json). This deliberately correlated training design reveals a compositional-generalization failure; it does not establish that all small molecular models or more balanced training regimes fail in the same way.

## Readout, replay, and correlation mechanisms

The [v3 protocol](configs/MECHANISM_V3_PROTOCOL.md) tests whether a changed readout is sufficient, where adaptation changes behavior, and whether counterexamples transfer to combinations that never receive direct labels. It preserves all prior archives and uses the existing hard-v2 molecular identities and model checkpoints.

The first diagnostics fit an explicit position-only predictor and train a local-subgraph positive control. The five-arm intervention fixes the same 32 new labels and, where applicable, 32 old labels: inherited heads with frozen encoders, full-model adaptation, both versions with replay, and random initialization with replay. The primary sample is fixed across all seeds and arms; two additional archived samples are supplemental checks. New-versus-old performance is measured throughout adaptation, with crossed encoder/head states and fresh frozen-feature ridge diagnostics at the end.

The subsequent correlation experiment replaces 0%, 1%, 5%, or 20% of a fixed-size training set with counterexamples from four motif types. Four other motif-position combinations remain completely excluded. Direct learning of exposed combinations and generalization to protected combinations are reported separately.

```powershell
.\.venv\Scripts\python.exe -m jcim.mechanism_diagnostics --source experiments\hard_v2 --output experiments\mechanism_diagnostics_v3
.\.venv\Scripts\python.exe -u -m jcim.mechanism --config configs\mechanism_v3.json --source experiments\hard_v2 --output experiments\readout_replay_v3
.\.venv\Scripts\python.exe -u -m jcim.correlation --config configs\mechanism_v3.json --source experiments\hard_v2 --output experiments\correlation_v3
```
